# Template LinkedIn - Nerd Severino

## Estrutura (máx 3000 caracteres)

```
[Hook - 1 linha que gera curiosidade, aparece antes do "ver mais"]

[Espaço]

[Problema - 2-3 linhas identificando a dor]

[Solução - 3-5 bullets com os pontos principais do post]

[Resultado/Insight - 1-2 linhas com o takeaway]

[Pergunta para engajamento]

🔗 Link completo nos comentários

#hashtags (5-8 relevantes)
```

## Regras
- Hook FORTE na primeira linha (aparece no feed antes do "ver mais")
- Máximo 1300 caracteres (ideal para mobile)
- Bullets com emoji para scanability
- Pergunta aberta no final (gera comentários)
- Link nos COMENTÁRIOS (LinkedIn penaliza links no post)
- Publicar terça a quinta, 8h-10h
- Não colar o artigo inteiro
